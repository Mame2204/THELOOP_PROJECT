## Rappel : pourquoi ne pas contacter « tout le monde » en novembre

À distance, sur un concept inconnu + contexte arnaques → faible conversion et **usure de crédibilité**.  
Le message gagnant inclut : **« J’arrive le 7, on se voit le 8 »** — crédible à partir de **début décembre**.
