# THE LOOP Pass — Stratégie marketing B2B (Guinée)

## 1. Nature du projet

- **Produit :** THE LOOP Pass — solution de **fidélisation digitale** pour commerces à Conakry (et extension possible).
- **Modèle :** agence **white-label Boomerangme** (cartes Apple Wallet / Google Wallet, scan en boutique, campagnes, sous-comptes commerçants).
- **Cible :** **commerçants B2B** (pas le grand public).
- **Vitrine :** https://pass.theloop-app.com
- **House brand :** **AELY** (https://aelygroup.com) — solutions numériques & data, Conakry.
- **Statut au lancement terrain (décembre 2026) :** commercialisation Pass sous marque AELY ; **immatriculation formelle (RCCM / factures)** visée **janvier 2027** (voir documents 09 et 11).

## 2. Contexte marché

- La **fidélisation structurée** (carte papier ou digitale) est **quasi absente** à Conakry → **création de catégorie** : il faut **éduquer** et **montrer en live**, pas convaincre par la pub de masse.
- **Confiance faible** en ligne (arnaques) → la vente repose sur **présence physique**, **démo gratuite**, **pas de paiement avant RDV** pour les prospects froids.
- **Canal dominant :** WhatsApp + **visite boutique** + recommandations.

## 3. Positionnement

**Promesse commerçant (une phrase) :**  
*Vos clients reviennent — carte sur leur téléphone, sans app à installer pour eux ; vous scannez en boutique ; on configure tout avec vous.*

**Ce que vous vendez (réel) :**

| Bénéfice | Formulation terrain |
|----------|---------------------|
| Rétention | « Voir qui revient, pas seulement qui passe une fois. » |
| Simplicité client | QR → Wallet / Google / PWA si téléphone ancien. |
| Simplicité staff | Scan = tampon ou point en quelques secondes. |
| Relance | Messages / campagnes selon l’offre. |
| Accompagnement | Mise en place gérée ; essai 14 jours. |
| Image | « Parmi les premiers à Conakry à proposer ça. » |

**Ce que vous ne promettez pas sans preuve locale :** chiffres type « +30 % de CA » (Boomerangme US) tant que vous n’avez pas vos propres retours Guinée.

## 4. Secteurs visés (non exclusif)

Ordre **de démo** recommandé, prospection **large** :

1. Parfums, bijoux, mode, accessoires (luxe / premium) — panier moyen, image.
2. Instituts de beauté, salons de coiffure — fréquence, rendez-vous.
3. Restaurants, cafés — volume, effet tampon visible.
4. Autres : retail, services, événements (pack ouverture).

**Pilote initial :** commerce **accessoires de luxe** (vente en ligne vers la Guinée, présence sur place en décembre).

## 5. Stratégie « com » : ce qu’on fait / ne fait pas

### On ne fait pas

- Calendrier éditorial type **The Loop guide** (Reels, stories, grand public).
- Mélanger **liste d’attente app** et **Pass commerçants** sur les mêmes posts (sauf mention pro exceptionnelle).
- Vente à froid **« payez par WhatsApp »** sans avoir rencontré le client.

### On fait

| Levier | Rôle |
|--------|------|
| **Site Pass** | Crédibilité, prix, essai 14 j, CTA WhatsApp |
| **Carte de visite** | Multi-projets ; ligne Pass + URL + tel |
| **Flyer A5** (optionnel) | À laisser après RDV |
| **WhatsApp Business** | Réponses rapides, statuts discrets |
| **Liste & prospection** | IG/FB → numéro → message → RDV |
| **Démo live** | Cœur de la conversion |
| **Bouche-à-oreille** | Pilote + premiers signés |

**Page Facebook / Instagram dédiée Pass :** **non obligatoire** avant ~10 commerces actifs. Le site + WhatsApp suffisent au démarrage.

## 6. Funnel commercial

```
Repérage (RS, reco, terrain)
    → WhatsApp / appel (créneau RDV)
        → Démo live 15–20 min
            → Essai technique 14 jours (config + QR)
                → Fin d’essai : accord ou arrêt
                    → Abonnement mensuel (facturation d’avance)
```

**Signature :** possible **au RDV** avec **facturation différée au 1er janvier 2027** (voir convention d’essai), ou **après** les 14 j si vous préférez moins d’engagement écrit avant preuve d’usage.

## 8. Synergie The Loop (guide app)

- **Plus tard**, quand le guide public tourne : offre bundle « visibilité + Pass » pour partenaires.
- **Décembre 2026 :** vendre **Pass seul** ; ne pas compliquer le pitch.

## 9. Indicateurs (6 premiers mois)

- RDV démo / mois
- Essais 14 j activés
- Taux essai → payant
- Commerces actifs payants
- Scans / semaine / commerce (preuve d’usage)
- Churn trimestriel

## 10. Risques & parades

| Risque | Parade |
|--------|--------|
| Produit inconnu | Démo live > slides |
| Coût white-label Boomerangme | 3 pilotes avant engagement long ; marge par commerçant |
| Confusion marques Loop | URL Pass distincte, vocabulaire « commerçants » |
| Téléphones anciens | Activer **PWA + Google Wallet** sur chaque carte |
| Société pas encore créée | Convention au nom du porteur de projet + avenant janvier (doc 09, 11) |
