# THE LOOP Pass — Playbook démo live (15–20 min)

## Avant le RDV

- [ ] Téléphone chargé ; démo **vitrine** + accès **admin** pilote si besoin  
- [ ] Carte de visite + **convention** (09) + **CGV** (10) en PDF ou papier  
- [ ] Connexion data OK (ou mode dégradé : captures + carte déjà installée sur ton tel)  
- [ ] Noter : nom gérant, **qui scanne** au quotidien, flux client (file, table, comptoir)

---

## Déroulé minute par minute

### 0–2 min — Accueil & question

- « Merci de me recevoir. Je ne vais pas vous bombarder de technique : en **15 minutes**, vous verrez ce que **vos clients** verront. »  
- **Une question :** « Aujourd’hui, comment savez-vous si un client **revient** ? » (carnet, tête, rien…)

### 2–5 min — Côté client (sur LEUR téléphone)

1. Montrer le **QR** (affiche ou écran).  
2. Ils scannent → formulaire → **Ajouter à Wallet / Google / PWA**.  
3. « Vos clients font ça **une fois**. La carte reste dans le téléphone. »

**Points à dire :**

- Pas d’app The Loop à télécharger.  
- Si téléphone ancien : **PWA** (bouton sur le formulaire d’installation).

### 5–10 min — Côté commerçant (scan)

1. Ouvrir **Scanner App** (ou navigateur scanner).  
2. Scanner la carte du client → **+1 tampon / point**.  
3. Montrer la **récompense** (ex. 10e visite = avantage).

« **2 secondes** au comptoir — la personne qui encaisse peut le faire. »

### 10–13 min — Tableau de bord (léger)

- Nombre de **clients** / **installations**.  
- **Historique** des visites (sans noyer dans les menus).  
- « Vous pourrez envoyer un **message** aux clients inactifs » (selon offre).

### 13–16 min — Leur métier

Adapter 2 phrases (voir fichier 05) :

| Secteur | Accroche |
|---------|----------|
| Luxe / parfums / bijoux | « Client qui achète en ligne ou en boutique — la carte lie les **achats répétés** et vous laisse un **contact** propre. » |
| Salon / institut | « Chaque rendez-vous = tampon ; la **10e visite** = soin ou réduction. » |
| Resto | « Le tampon après le repas ; récompense **boisson / dessert** — simple pour la salle. » |

### 16–18 min — Offre & essai

- **14 jours d’essai**, sans engagement pendant l’essai.  
- **Mise en place offerte** (premiers commerçants).  
- **3 formules** — une phrase chacune (Essentiel / Pro / Prestige).  
- **Facturation** : « Si vous validez, l’abonnement peut démarrer **au 1er janvier** — on signe aujourd’hui le cadre, **pas de paiement aujourd’hui** si on est d’accord. »

### 18–20 min — Prochaine étape

- « Qui sera la personne qui **scanne** tous les jours ? »  
- « On installe le **QR** où : caisse, vitrine, table ? »  
- Proposer **signature convention** + date de début essai **aujourd’hui** ou **demain**.

## Erreurs à éviter

- Montrer **tous** les menus Boomerangme.  
- Promettre des **%** de CA sans data locale.  
- Demander **Orange Money** avant confiance établie (prospect froid).  
- Enregistrer vidéo **sans** accord explicite.
