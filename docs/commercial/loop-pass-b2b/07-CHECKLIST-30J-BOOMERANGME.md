# THE LOOP Pass — Checklist 30 jours essai Boomerangme (Agence)

## Objectif de la période

À la fin des ~30 jours, vous devez pouvoir répondre **sans théorie** :

- Est-ce que l’outil **couvre** ce que je vends aux commerçants guinéens ?  
- Quelles **limites** par plan Essentiel / Pro / Prestige ?  
- Quels **arguments** et **captures** pour la démo live ?  
- Est-ce que **Wallet + scan + PWA** fonctionnent **en Guinée** ?

---

## Semaine 1 — Fondations agence

- [ ] Compte **Agency** + branding (logo, couleurs, domaine si white-label actif)  
- [ ] Comprendre **dashboard revendeur** : sous-comptes, plans, renouvellements  
- [ ] Créer **sous-compte 1 — Vitrine démo** (commerce fictif Conakry)  
- [ ] Créer carte **tampon** ou **points** ; activer **Google Wallet + PWA**  
- [ ] Tester **Scanner App** (iOS + Android si possible)  
- [ ] Noter dans carnet (fichier 08) : temps de création carte, points bloquants  

---

## Semaine 2 — Pilote & second métier

- [ ] **Sous-compte 2 — Pilote luxe** (accessoires) : logo, règles, QR  
- [ ] Envoyer accès **contact Guinée** : installation client + scan  
- [ ] **Sous-compte 3 — Autre secteur** (ex. institut beauté) pour montrer variété  
- [ ] Tester **push** / 1 campagne simple (si incluse dans plan)  
- [ ] Documenter : **numéro pays** (+224), masque téléphone formulaire  

---

## Semaine 3 — Alignement offres commerciales

- [ ] Tableau **Essentiel / Pro / Prestige** : fonctionnalités Boomerang vs service humain  
- [ ] Prix GNF : marge après coût Agency + ~15 USD / sous-compte actif  
- [ ] Process **onboarding** : logo, couleurs, règle récompense, QR print  
- [ ] Kit QR : export affiche / lien carte  
- [ ] Lire doc **géolocalisation push** (si vous la vendez en Prestige)  

---

## Semaine 4 — Preuves & décision go / no-go

- [ ] Retour **Guinée** : Wallet OK ? PWA OK ? Scan OK ? Réseau lent ?  
- [ ] Retour **pilote luxe** : clients ont installé ?  
- [ ] **3 captures** minimum pour démo (formulaire, wallet, admin)  
- [ ] Mettre à jour fichier **05** (arguments réels)  
- [ ] Mettre à jour fichier **06** (site)  
- [ ] Décision : **poursuivre abo Agency** après essai ? (seuil : 1–3 commerçants prêts à payer en janv.)
