# Statut programmation Meta · **chaque jour, chaque publication**

**Heure par défaut :** 19h00 (Conakry) · **FB + @app.theloop** · lieu Conakry.  
**Détail (légendes, UTM) :** fiches `fiches/XX-YYYY-MM-DD.md` · lots `17-LOT-A`…

## Comment lire le tableau

| Colonne **Programmé Meta** | Signification |
|----------------------------|---------------|
| **Oui** | Créneau posé dans Business Suite (média + texte) |
| **Non** | Pas encore dans Meta |
| **—** | Rien à programmer pour ce créneau |

| Colonne **Jour J** | Signification |
|-------------------|---------------|
| **—** | Rien de plus à faire ce jour-là |
| **Lien story (app)** | Story déjà programmée **sans** sticker lien → ajouter le lien depuis l’**app** le jour de publication |
| **Décompte** | Story **non** programmable à l’avance → choisir `STORY_COMPTEUR_reste-XX.png` selon inscrits |
| **Sondage (app)** | Story sondage **uniquement** depuis l’app (sticker Sondage) |
| **Boost** | Lancer / vérifier le boost le jour J (plan attraction) |
| **Relais WA** | Message WhatsApp relais (fiche du jour) |

**Convention (depuis nov.) :** stories souvent **sans lien** dans Meta → **Lien story (app)** le soir de publication.

**Liste complète des stories + URL sticker :** `STORIES-LIEN-JOUR-J.md`
