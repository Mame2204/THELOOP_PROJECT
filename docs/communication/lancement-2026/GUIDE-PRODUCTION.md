# Guide production visuels & vidéos

## CapCut ou Canva ? → **CapCut** (choix unique)

| | **CapCut** | Canva |
|---|------------|--------|
| Vidéos 9:16 Facebook | ✅ Natif | Possible mais moins fluide |
| Sous-titres FR | ✅ Auto | Limité en vidéo |
| Son + coupes | ✅ | ❌ |
| Carrousels statiques | OK (import PNG) | ✅ |
| Coût | Gratuit suffisant | Gratuit suffisant |

**Workflow :** visuels PNG depuis `export-visuels-pack1.html` → import CapCut → tes clips + captures → export Reels/feed.

Canva : **inutile** si tu suis ce flux (sauf si tu préfères déjà Canva pour tout refaire à la main).

## L’agent peut-il se connecter à CapCut / Canva ?

## Export PNG

1. Ouvrir `export-visuels-pack1.html` dans Chrome (fichier local).
2. Zoom 100 %, fenêtre assez large pour 1080px slide.
3. Capture d’écran par slide (ou DevTools device 1080×1350).

## CapCut — ordre vidéo 17/11 (rappel)

1. Bruit 3 s → coupure
2. Importer PNG « Tout crie » / « Peu de choses guident » / etc.
3. Importer clip capture floutée 4 s
4. PNG « Réserve ta place »
5. Voix off ou texte seul + sous-titres
6. Export 1080×1920, 30 fps
