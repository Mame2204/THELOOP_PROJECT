# Scénario vidéo 17/11 · « Vendredi soir · le scroll »

**Format :** 9:16 · **40–48 s** · voix off (sans prénom) · **pas de visage** · mains + **enregistrements d’écran** réels.

**Idée :** vendredi soir → tu cherches un plan week-end sur **Facebook / Instagram / TikTok** → bruit, répétition, nom oublié → **The Loop** = repère → **liste ouverte**.

## Pourquoi ça marche

- Public Conakry **vit** déjà le scroll du vendredi.
- Pas de **faux lieux** (Penthouse…) dans l’accroche : réseaux réels, problème réel.
- Transition **problème → solution** claire avant l’annonce du 17/11.

## Optimisations

1. **Rythme :** aucun plan réseau **> 2,5 s** ; coupes sèches entre FB / IG / TikTok.
2. **Message « bruit »** : montrer **3× le même type** de contenu (deux stories food, deux reels soirée) + **recherche avortée** = mieux qu’un long discours.
3. **The Loop** : **enregistrement écran**, pas PNG — la vidéo « reprend vie ».
4. **Fin 17/11** : ne pas oublier l’annonce **liste ouverte** (cover) — ce n’est pas une pub « télécharge l’app » le jour J.
5. **MOOD_*.png** : optionnel en **15–16 s** seulement si tu n’as pas de bonne coupure ; sinon **sauter** les cartes statiques.
