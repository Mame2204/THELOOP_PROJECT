# Guide production visuels & vidéos

## CapCut ou Canva ? → **CapCut** (choix unique)

| | **CapCut** | Canva |
|---|------------|--------|
| Vidéos 9:16 Facebook | ✅ Natif | Possible mais moins fluide |
| Sous-titres FR | ✅ Auto | Limité en vidéo |
| Son + coupes | ✅ | ❌ |
| Carrousels statiques | OK (import PNG) | ✅ |
| Coût | Gratuit suffisant | Gratuit suffisant |

**Workflow :** visuels PNG depuis `export-visuels-pack1.html` → import CapCut → tes clips + captures → export Reels/feed.

Canva : **inutile** si tu suis ce flux (sauf si tu préfères déjà Canva pour tout refaire à la main).

## L’agent peut-il se connecter à CapCut / Canva ?

**Non** — pas d’accès à tes comptes (sécurité + pas d’automation fiable).  
**Oui** pour : HTML exportables, scripts, SRT, assets dans `assets/`, instructions montage.

## Contenu démo dans les captures (fictif)

Les écrans sont de **vraies captures de l’application** (UI réelle) ; seules les **données saisies** (événements, lieux, textes, médias) sont **inventées** pour éviter d’afficher du contenu réel sans accord. **Aucun établissement ou événement réel** n’est représenté.

- **Com nov.–déc. :** tu peux utiliser ces captures **sans flou “legal partenaire”** — ce n’est pas du naming réel.
- **Flou partiel** reste utile seulement pour le **teasing** (montrer la forme, pas tout le produit avant le 17/12) ou par esthétique ; ce n’est plus une obligation juridique sur ces libellés fictifs.
- **Quand de vrais partenaires seront publiés :** remplacer les fiches démo par du contenu signé charte ; adapter les visuels com en conséquence (accord écrit pour tout nom réel).

## Export PNG

1. Ouvrir `export-visuels-pack1.html` dans Chrome (fichier local).
2. Zoom 100 %, fenêtre assez large pour 1080px slide.
3. Capture d’écran par slide (ou DevTools device 1080×1350).

## CapCut — ordre vidéo 17/11 (rappel)

1. Bruit 3 s → coupure
2. Importer PNG « Tout crie » / « Peu de choses guident » / etc.
3. Importer clip capture floutée 4 s
4. PNG « Réserve ta place »
5. Voix off ou texte seul + sous-titres
6. Export 1080×1920, 30 fps
