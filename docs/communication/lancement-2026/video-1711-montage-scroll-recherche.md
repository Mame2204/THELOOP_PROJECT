## 2. Le Fragment — lire l’image (pas de VO « bruit »)

Sur la capture type **Le Fragment**, l’écran affiche en général :

- Surtitre : **Le Fragment**
- **Titre** éditorial (ex. *Le seuil*, pas « réseaux sociaux »)
- **Corps** : texte calme — transmission, regard, seuil, cercle, ambiance… (pas le fil Instagram)

**Conclusion montage :**

- **Ne pas** mettre en overlay *Trop de bruit. Peu de repères.* sur ce plan (ça contredit le texte à l’écran).
- **Ne pas** lire *Posts, stories, reels…* pendant le Fragment.
- **Durée : 7 à 8 s** (minimum 6 s) pour laisser lire titre + 1er paragraphe.
- **Texte CapCut sur le Fragment : aucun** (ou seulement un tout petit *Le Fragment* si tu veux — optionnel).
- **VO sur le Fragment (au choix)** :
  - **A (recommandé)** : silence + pad très bas · le viewer lit ;
  - **B** : une ligne qui **suite** le texte : *« Les bonnes adresses ne s’annoncent pas. Elles se transmettent. »*
  - **C** : enchaînement direct : *« The Loop, c’est un guide sélectif pour Conakry. »* (sans parler de bruit).
