# Voix off — tu parles, The Loop pense

Tu as choisi une **voix humaine** (la tienne). Bon pour la confiance, une fois ou sur plusieurs vidéos — sans devenir la « vedette » visuelle.

## Règle simple

- **À l’écran / légende :** marque **The Loop**, pas de storytelling perso.
- **À la voix :** tu peux lire les scripts tels quels (3ᵉ personne / « on » implicite via The Loop) **ou** une variante **« je »** légère uniquement sur **6/11** et **13/11** (dilemme du week-end), jamais sur les slides texte.

## Avant enregistrement (iPhone)

1. Pièce calme, serviette / placard si besoin.
2. **Dictaphone** → lire le bloc voix du script en **2–3 prises**.
3. CapCut : importer vidéo + **extraire audio** ou importer le .m4a, **couper** les respirations.
4. Parler **plus lentement** que en conversation ; phrases courtes des scripts.

## Scripts « voix Mariame » option 6/11 (si tu préfères « je »)

Remplacer la VO The Loop par :

> « Vendredi, même question. *On fait quoi ce week-end ?* Même réponses. The Loop arrive pour simplifier ça. »

**17/11 — garder voix neutre (recommandé) :** le script « La fréquence » sans « je » ; tu es la voix, pas le personnage.

## Decembre sur place

B-roll (mer, route, terrasse) + ta VO ou texte seul ; prioriser **son ambiant** si pas le temps de VO.
