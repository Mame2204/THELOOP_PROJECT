# Contenu fictif dans l’app (captures stores)

Les écrans utilisés pour **Apple / Google (validation stores)** contiennent des **données inventées** : événements, lieux (ex. « Penthouse »), dates, sondages, prénom dans l’accueil, etc. **Ce n’est pas du contenu réel** et **ne doit pas être lu ou promu** comme tel en communication publique.

## Règle com

| Usage | OK ? |
|-------|------|
| Publier un lieu / événement **lisible** (Les Passages, Penthouse, 24 déc.…) | **Non** — risque de confusion à Conakry + promesse fausse |
| Montrer l’**interface** (navigation, structure, typo, couleurs) | **Oui**, si textes fictifs **illisibles** (flou fort, crop, ou captures « com » refaites) |
| Texte éditorial **générique** sans faux lieu (ex. fragment « ville / bruit / ce soir ») | **Oui**, si aucun nom d’événement ou lieu inventé visible |
| Photos **hors app** (ambiance, Conakry, lifestyle) | **Oui** — privilégier pour l’accroche et le « sélectif » |
